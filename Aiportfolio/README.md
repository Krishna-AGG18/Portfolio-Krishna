# Krishna Aggarwal - Creative Developer Portfolio

An ultra-premium, interactive personal portfolio built to showcase my skills as a Full Stack Developer. Designed with a custom "brutalist glassmorphism" aesthetic, this portfolio features a bespoke fluid particle engine, high-performance scroll animations, and dynamic 3D interactions.

🔗 **Live Preview:** [Live Link]
(KRISHNAAGGARWAL.NETLIFY.APP)

---

## ⚡ Features

- **Custom Fluid Particle Engine:** A high-performance, `requestAnimationFrame` driven canvas background that responds to scroll depth, smoothly transitioning colors from crimson to gold to cyan as you explore the site.
- **Premium Animations:** Deep integration with **Framer Motion** and **GSAP** for buttery-smooth page loads, scroll-triggered text reveals, and parallax depth effects.
- **Interactive 3D Elements:** The Projects section features custom CSS 3D transforms to create sleek flipping project cards.
- **Brutalist Glassmorphism:** A completely customized UI that avoids generic templates, featuring massive typography, stark outlines, and deep layered background blurs.
- **Fully Responsive:** Painstakingly audited layout ensuring that the massive typography, grids, and overlays look intentional and perfectly centered on mobile devices.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React 18)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) & [GSAP](https://gsap.com/)
- **Icons:** [Lucide React](https://lucide.dev/) & React Icons
- **Typography:** Geist Sans / Mono (Optimized via `next/font`)

## 🚀 Getting Started

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Krishna-AGG18/Portfolio-Krishna.git
   cd Aiportfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Explore:**
   Open [http://localhost:3000](http://localhost:3000) in your browser.
